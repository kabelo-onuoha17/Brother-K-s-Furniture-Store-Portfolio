Project Overview

Brother K's Furniture Store is a 5 page responsive website designed for a family business based in Maboneng, Johannesburg. The platform showcases handmade wooden furniture, provides transparent pricing details, features an interactive enquiry form, and displays store operational hours with an embedded Google Map location.



 Part 3 Enhancements

1. Client-Side Form Validation: Added custom JavaScript input checks inside "script.js" to validate name, email formatting, and phone number lengths prior to form submission.
2. Interactive Image Lightbox: Added dynamic DOM manipulation enabling users to click on product images to view them inside a full-screen interactive lightbox overlay.
3. On Page SEO Optimization: Configured target keyword meta descriptions, title tags, semantic header hierarchies (<h1>-<h3>), and accessible "alt" text across all web pages.
4. Off Page & Technical SEO: Created a standard "robots.txt" crawler instruction file and a structured XML sitemap (sitemap.xml) to optimize search engine indexation.
5. Live Deployment: Deployed the completed repository live on Netlify for access across all devices.
